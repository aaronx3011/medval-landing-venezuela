# Medval Supplies Brand

## Approved Assets

- Primary wordmark: `public/medval.svg`
- White wordmark (dark surfaces and login): `public/medval-white.svg`
- Standalone mark: `public/medval-mark.svg` (white: `public/medval-mark-white.svg`)
- App/admin icon and favicon: `public/medval-icon.svg`

Use these Medval assets in the admin panel and the public site. Do not use Payload branding in the admin.

## Core Colors

| Name | CSS token | Hex | Use |
| --- | --- | --- | --- |
| Medval orange | `--color-primary` | `#E97829` | Calls to action and highlights |
| Medval purple | `--color-secondary` | `#3C3A78` | Primary surfaces and typography |
| Deep purple | `--color-secondary-dark` | `#2B2957` | Darker surfaces and contrast |

The purple and orange are the fills embedded in the approved wordmark. Branded component surfaces, outlines, focus states, and highlights must use these exact tokens; reserve neutral colors for surfaces, borders, and readability.
